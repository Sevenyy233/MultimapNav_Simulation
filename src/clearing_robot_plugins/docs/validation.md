# 清障机器人导航验证记录

> 此文件是此前固定GridMap入口的历史验收。最新18盒体及运动修正见 [运动修正验证](motion_refinement_validation.md)。较早的自动/强制地图模式、实际地图话题接入和插件拆分验证见 [地图模式验证](map_modes_validation.md)。

日期：2026-10-27。环境：ROS 2 Humble、Gazebo Classic、默认封闭场景，机械臂收起，导航限速 0.35 m/s、0.18 rad/s。所有物理参考状态仅用于测试断言，没有向定位或控制发布真值里程计。

## 实际仿真结果

| 场景 | 结果 |
| --- | --- |
| 未知箱体绕行，第1次 | 成功；实际终点误差 0.108 m，定位终点误差 0.032 m |
| 同一场景连续第2次 | 成功；实际终点误差 0.072 m，定位终点误差 0.027 m |
| 直行6 m后转90°再行驶6 m | 成功；最终目标误差 0.133 m，定位误差 0.015 m |
| 感知进程暂停5 s再恢复 | 实际速度降到 0.0040 m/s；恢复后继续完成导航，目标误差 0.260 m |
| 初始定位种子偏置0.5 m、0.3 m和0.05 rad | 重定位序号增至 2，恢复后位置误差 0.029 m |
| 后退恢复 | 实际后退 0.586 m（设置0.6 m，速度0.10 m/s） |
| 旋转恢复 | 实际旋转 0.249 rad，即 14.3°（设置0.26 rad，速度0.06 rad/s） |
| RViz | 已检查实际主窗口：15个碰撞盒体、五路融合点云、先验地图与导航工具可显示，没有话题QoS不兼容警告 |

绕行测试将1 × 1 × 1.5 m的箱体加入先验地图中不存在的位置(5.5, 5.5)，目标为(10, 6, 0)。必须先确实收到箱体回波，再执行导航。沿实际物理运动，以独立的有向盒体分离轴检查检测全部15个盒体，两次共 **629 次检查均未碰撞**；不是仅检查机器人中心或规划路径。两次全程采样位置定位误差的最大值为 **0.054 m**。这些是本场景的测量结果，不能外推为任意环境下的零漂移保证。

## 回归检查

- 20项Python检查：机器人几何、外参、布局、收臂反馈新鲜度及停止判定。
- 4项C++几何/规划检查：共享Marker几何、坡度/侧倾、论文搜索与曲线、转动中间扫掠；同时复现终点连接和全局路径复用问题。
- 4项速度估计检查。
- 五雷达原始融合契约：五路外参一致、自体回波剔除、融合输入不依赖里程计。
- 转动融合契约：采集时刻剔除铲斗回波，再进行0.35 rad运动对齐；真实密集障碍保留，孤立射线在进入记忆前剔除。

## 已处理的问题

仅前向单雷达输入的FAST-LIO2曾出现明显侧向漂移，导航入口改为五雷达IMU坐标系融合。转动自体回波需在运动对齐前过滤；新增障碍采用空间去噪及10 s观测记忆。MPPI必须尊重局部路径的原地转向点，并复核加加速度、位姿年龄和反应时间下的停车包络。全局路径简化后须加密采样，重规划失败时只保留经过完整三维复核的同目标剩余路径。启动时用实际关节反馈确认收臂，处理控制器已执行而DDS动作回复丢失的情况。RViz已按[Humble官方话题属性定义](https://github.com/ros2/rviz/blob/humble/rviz_common/include/rviz_common/ros_topic_display.hpp)修正MarkerArray `Topic` 配置，并修正局部路径的Volatile QoS。

## 适用边界与复现

本次物理验收覆盖平地、收臂、低速仿真；坡地行驶、履带土壤接触辨识、机械臂动态运动和稀疏小目标检测未作为通过的物理场景。纸面算法为单高程层搜索，不保证SE(2)完备或严格最短。定位通过先验地图匹配约束漂移，质量不足时停止，不能承诺绝对零漂移。定向雷达仍有盲区，观测记忆不等于完整空间覆盖。
